# 你好，Markdown

把注意力留给文字。这里可以阅读，也可以直接修改。

## 从一份文档开始

点击这段文字，就能编辑它的 Markdown。点击其他段落后，文字会重新排版。顶部的 **源码** 按钮可以查看完整原文。

- **打开**：按 ⌘O，或拖入一个本地文件。
- **保存**：已有文件会自动保存，也可以按 ⌘S。
- **接着读**：左侧最近文件会记住你的阅读位置。

## 常用内容，都在这里

| 内容 | 怎么用 |

| 搜索与替换 | 按 ⌘F，输入要找的文字 |
| 图片 | 粘贴、拖入，或用菜单插入 |
| 代码 | 指定语言即可高亮，右上角一键复制 |
