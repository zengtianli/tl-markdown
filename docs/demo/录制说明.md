# Folio 实机素材

素材必须由当前最终包的真实窗口取得。此目录只包含合成输入和分镜，不包含伪造截图。

先运行 `python3 scripts/prepare-demo.py`，会在全新的 `build/demo/<时间>/` 下创建独立会话与可编辑文档，并打印环境变量。脚本不启动应用、不设置系统默认打开方式、不触碰剪贴板或用户会话。录制者通过已确认输入隔离的 Computer Use 接口使用该会话；若启动接口不能传环境，请先解决隔离路径，不能打开用户会话混拍。

录制目标应为发行清单所对应的 Folio 包；保持实际窗口边界，侧栏可改为“大纲”，使截图不含用户目录。三个片段可以独立录制，每段开始前先录后操作，不用加速证明响应速度。

| 成片 | 起点 → 操作 → 可见结果 | 独立验证 |
| --- | --- | --- |
| `open.mp4` | 欢迎页 → 打开合成“写作样例.md” → 主区标题与三列表格完成渲染；侧栏切“大纲” | 标签名正确，主区出现“本周的小计划”，不是独立预览窗口 |
| `edit.mp4` | 主区表格 → 点击“进行中”，替换为“已经完成” → 点击下一段，表格重新排版；切源码再返回 | 磁盘中的同一行是“已经完成”，正文其他行未变 |
| `save.mp4` | 同一文档显示编辑结果 → 等底栏“已保存” → 关闭标签，再从最近文件打开 → 结果仍在 | `python3 scripts/verify-demo.py <运行目录>` 读取真实 Markdown 并核对修改及完整性 |

建议每段 12–20 秒，字幕用清楚的动作和结果，不遮挡底栏“已保存”。烧录中文字幕，并提供 UTF-8 WebVTT；字幕由真实原片切点产生。合片可额外提供，不是三个必需片段的替代。

最终网站读取 `docs/demo/media/`：

- `folio-editor.png`：最新主编辑器真实窗口，至少 1000 像素宽；建议表格与段落同屏。
- `open.mp4`、`edit.mp4`、`save.mp4`：H.264、yuv420p、faststart，带声音时用 AAC。
- 同名 `.jpg` 海报和 `.vtt` 字幕。
- `capture.json`：格式见下。环境/版本来自实际录制，不能把示例值当结果。

```json
{
  "app_version": "从包内读取",
  "app_build": "从包内读取",
  "recorded_at": "实际 ISO 时间",
  "environment": "实际 macOS 版本与设备",
  "source": "real-app-window",
  "synthetic_input": true,
  "scenes": ["open", "edit", "save"],
  "notes": "实际剪辑、补拍和未覆盖范围"
}
```

正式站构建会要求所有媒体和版本清单齐全，校验 MP4/VTT/图片并拒绝缺片；`--preview` 只供内部文案与布局预览，禁作为完成站发布。原片留在 `build/demo/` 私有目录；仅审核后的成片进入 `docs/demo/media/`。
