# Folio · 文页 1.2.0

Folio 自带 Markdown 全文索引与目录图谱：侧栏搜索改读 Folio 自己的索引，公开下载的用户添加索引文件夹后即可使用；应用包内另附同一引擎的 `folio` 命令。

## 新增

- 设置页新增「索引文件夹」（可增删）和「更新索引」：后台低优先级增量更新，可取消，显示上次更新时间和篇数。没有索引时，搜索面板引导选择文件夹。
- 菜单「文件 → 生成目录图谱…」：选一个文件夹，生成离线的 `知识图谱.html` 并用默认浏览器打开；已有非 Folio 生成的同名文件时拒绝覆盖。
- 应用包内附带 `folio` 命令（`Folio.app/Contents/Resources/bin/folio`，与界面同一引擎）：`folio index / search / files / stats / graph`。下载版需手动链接到 `~/.local/bin/folio`，用法见 [docs/cli.md](../cli.md)。

## 使用条件

支持 Apple 芯片 Mac，要求 macOS 15 或更新版本。索引与图谱只依赖系统 SQLite，不需要 Python、Node.js 或常驻服务。没有配置索引文件夹时不扫描任何目录；索引与配置默认在 `~/Library/Application Support/TLMarkdown/`。

应用继续使用原来的 bundle ID 和本机状态目录；已设置的自定义索引位置和 `MDINDEX_DB` 继续生效。

## 分发与验证范围

现有打包流程生成本地 ad-hoc 签名的 ZIP，尚未经过 Apple 公证；不包含 Developer ID 或 App Store 发布承诺。

资源占用为本版发行包 1.2.0 (49) 实测（`perf/lightweight.json`，空闲门通过后测量）：下载 3.1 MB，解压后 7.6 MB，空闲内存约 108 MiB（主进程加 WebKit 辅助进程），空闲 CPU 0.03%，启动到可编辑 7 次中位 0.33 秒。

演示视频与主页截图仍为 1.0（构建 14）实录，本版有限复用：打开渲染、全部替换、保存后重开三段操作在 1.2.0 上原样成立；画面中的侧栏为旧版「最近文件｜大纲」，1.2.0 新增的「搜索」标签、索引设置与目录图谱未在视频中出现。页面标注录制版本。
