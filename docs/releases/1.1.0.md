# Folio · 文页 1.1.0

Folio 把跨笔记检索带到编辑器侧栏：找到内容后，可直接打开对应文档并跳到命中行。

## 新增

- 侧栏新增「搜索」，可用 ⌘⇧F 呼出；输入关键词后点击命中行，或按回车打开第一条结果。
- 检索只读本机已有的 md-index SQLite 全文索引；三个字及以上使用全文索引，较短关键词自动逐字匹配。索引位置可在设置中指定，缺失或不兼容时显示明确提示。
- 增加功能、恢复、隐私和原生界面的固定验收脚本；界面自检在独立状态目录中离屏创建实际视图，直接执行切换源码、重载、关闭等动作并检查结果，不合成鼠标或键盘输入。

## 使用条件

支持 Apple 芯片 Mac，要求 macOS 15 或更新版本。应用内置编辑资源，普通 Markdown 阅读、编辑和保存不需要另外安装 Python 或 Node.js；跨笔记检索需要已有的兼容 md-index 索引，Folio 不负责创建或更新它。

应用继续使用原来的 bundle ID 和本机状态目录。文档中的网络图片可能访问其原站点；点击外部链接会交给系统浏览器。

## 分发与验证范围

现有打包流程生成本地 ad-hoc 签名的 ZIP，尚未经过 Apple 公证；不包含 Developer ID 或 App Store 发布承诺。安装方法见产品主页，安装包校验值随包提供。

资源占用数据目前仍来自 1.0.1（构建 27）的实测，演示原片来自 1.0（构建 14）；两者不能作为 1.1.0 的性能或界面证据。新版性能数据与演示素材需单独补齐。
