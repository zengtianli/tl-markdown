# Folio · 文页 1.2.1

这一版补上「配置与更新」，并让 `folio` 命令覆盖界面里能看、能做的大部分事情。

## 新增

- 应用菜单「配置与更新…」：
  - 导出、导入阅读设置（正文字体、字号、正文宽度、启动时恢复、图片文件夹名）。
  - 「使用 iCloud 记住配置」：在登录同一 Apple 账户的 Mac 之间同步上述阅读设置，默认关闭；恢复前自动备份，损坏的配置不覆盖。文档、恢复草稿、索引文件夹和索引留在本机。
  - 「检查更新…」：读取产品主页的发行记录，显示当前版本与最新版本；有新版时给出下载或升级入口，装上新版后配置保留。只在点击时检查。
- `folio` 命令新增（完整说明见 [docs/cli.md](../cli.md)）：
  - `status`：一次读回版本、配置与索引库、索引文件夹、窗口会话摘要和阅读设置。
  - `read`、`write`、`outline`、`open`：按编辑器的规则读写文档、列出大纲、交给窗口打开（`open --example` 打开示例文档）。
  - `settings`、`settings set`：读、改阅读设置，范围与设置面板一致。
  - `recent`、`recent pin|unpin|remove|clear`：最近记录。
  - `tabs close|restore|reload`：关闭标签、恢复关闭的草稿、重新载入。
  - `config status|export|import|sync`、`update check|install`：「配置与更新…」窗口里的各项。
- 每个命令都支持 `--json`；失败输出带原因短码，退出码 0 / 1 / 2 分别表示成功、失败、用法错误。

## 行为说明

- 命令改阅读设置、最近记录或标签时，窗口开着由窗口应用并立即显示，窗口没开由命令直接写；两边不会互相覆盖。
- `folio write` 遇到文档在窗口里有未保存修改时拒绝写入，加 `--force` 才写，窗口标记冲突而不丢弃你的修改。
- 检查更新和升级只在你操作时联网；其余功能的联网范围不变。

## 使用条件

支持 Apple 芯片 Mac，要求 macOS 15 或更新版本。应用继续使用原来的 bundle ID 和本机状态目录，已有文档、最近记录和设置原样保留。下载版需手动把应用包内的 `folio` 链接到终端路径，见 [docs/cli.md](../cli.md)。
